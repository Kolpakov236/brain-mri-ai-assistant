# Отчёт об оценке модели

Модель: efficientnet_b0 (transfer learning), лучшая эпоха 12, val macro-F1 0.9772.
Все числа ниже посчитаны скриптом `python -m src.evaluate` на отложенной тестовой выборке (1100 снимков).

## Данные и разбиение

- Исходно 12064 файлов. Удалено точных дубликатов: 1172, синтетических аугментированных копий (суффиксы BR/DA/HF/RO/SP/VF): 3567, битых: 0. Осталось 7325.
- Штатное разбиение Train/Test не использовано: между ними найдены одинаковые снимки (утечка). Пул пересобран и разбит 70/15/15 стратифицированно по классам и по группам близких копий (4109 групп). Размеры: {'train': 5126, 'test': 1100, 'val': 1099}. Пересечений групп между выборками: {'train_val': 0, 'train_test': 0, 'val_test': 0}.
- **Ограничение:** идентификаторов пациентов в данных нет, поэтому разбиение по пациентам невозможно. Срезы одного пациента с разных ракурсов могут оказаться в разных выборках, метрики могут быть завышены.

## Локализация

Разметки области опухоли (маски, рамки) в данных нет, поэтому IoU/Dice посчитать нельзя. Локализация - слабо контролируемая (Grad-CAM, порог 50% от максимума, наибольшая связная компонента) и **приблизительная**. Примеры: `gradcam_examples.png`.

Косвенная проверка (закрытие области): на 150 верно классифицированных опухолевых снимках закрытие рамки Grad-CAM снижает уверенность в среднем на 0.244, закрытие случайной рамки того же размера - на 0.079; рамка Grad-CAM оказалась важнее случайной в 82.0% случаев. Средняя площадь рамки: 11.7% кадра. Это показывает важность области для решения модели, но не точность совпадения с границами опухоли.

## Анализ ошибок

Наиболее частые путаницы:

- менингиома -> предсказана как опухоль гипофиза: 4 из 246 (1.6%)
- менингиома -> предсказана как глиома: 4 из 246 (1.6%)
- глиома -> предсказана как менингиома: 3 из 339 (0.9%)

Сетка самых уверенных ошибок: `errors_grid.png`. Возможные причины: схожий вид менингиом и глиом на отдельных срезах, малые опухоли гипофиза, разный ракурс (аксиальный, коронарный, сагиттальный) и последовательность, разное качество исходных снимков.

## Ограничения

- Один составной источник данных, нет внешней валидации на снимках другой клиники и сканера.
- 2D-срезы вместо 3D-объёмов, нет клинических данных пациента.
- Нет ID пациентов: возможна остаточная утечка между выборками.
- Класс "норма" содержит иные последовательности (T2, FLAIR, разные ракурсы), чем часть опухолевых снимков: модель может опираться на тип последовательности.
- Локализация приблизительная (Grad-CAM), без разметки для количественной оценки.
- Результат носит вспомогательный характер и требует подтверждения врачом.

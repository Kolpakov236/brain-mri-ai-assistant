# ИИ-ассистент врача: обнаружение и локализация опухолей головного мозга на МРТ

Прототип для кейса "Здоровье под контролем ИИ" (хакатон "Медицина 2050", трек "Студенты").
Система принимает МРТ-снимок головного мозга, определяет класс (глиома, менингиома, опухоль гипофиза, опухоль не обнаружена), выделяет область, на которую опиралась модель, и выдаёт пояснение на русском языке.

**Это вспомогательный инструмент для врача, а не самостоятельное заключение и не медицинское изделие.**

## Результаты (отложенная тестовая выборка, 1100 снимков)

Все числа получены командой `python -m src.evaluate`, подробности в `reports/report.md` и `reports/metrics.json`.

| Показатель | Значение |
|---|---|
| Accuracy | 98.5% |
| macro-F1 | 98.4% |
| ROC-AUC (one-vs-rest, macro) | 0.9997 |
| Опухоль vs норма: чувствительность | 99.4% (пропущено 5 из 854 опухолей) |
| Опухоль vs норма: специфичность | 99.6% (1 ложная тревога из 246) |
| Recall: глиома / менингиома / гипофиз | 98.5% / 96.3% / 99.3% |
| ECE (калибровка) | 0.053 |

Важно читать вместе с разделом "Ограничения": высокие метрики получены на одном составном наборе без разбиения по пациентам и без внешней валидации, поэтому могут быть завышены.

## Подход

- **Ветка A (только метки классов):** в данных нет масок и рамок, поэтому локализация слабо контролируемая.
- Классификатор: EfficientNet-B0 (timm, предобучение ImageNet), вход 224x224, серый снимок повторён в 3 канала.
- Локализация: Grad-CAM (pytorch-grad-cam) на последнем свёрточном слое, порог 50% от максимума, наибольшая связная компонента, контур и рамка. Для класса "опухоль не обнаружена" область не выделяется.
- Обучение: AdamW, OneCycle, взвешенный CrossEntropy + label smoothing 0.05, early stopping по val macro-F1, seed 42. 12 эпох, около 31 минуты на Apple M2 (MPS).

### Подготовка данных (то, что важно для честной оценки)

- Исходно 12 064 файла. Удалено 1172 точных дубликата (по md5) и 3567 синтетических копий, которые уже были в наборе (суффиксы BR, DA, HF, RO, SP, VF в именах: яркость, поворот, отражения, шум). Осталось 7325 снимков, битых файлов нет.
- Штатное разбиение Train/Test **не используется**: между ними есть одинаковые снимки (утечка). Пул пересобран и разбит 70/15/15 (5126 / 1099 / 1100) стратифицированно по классам и по группам близких копий (4109 групп, поиск по dHash, включая зеркальные копии). Пересечений групп между выборками нет.
- Предобработка единая для всех источников: в градации серого, ресайз с сохранением пропорций и чёрными полями до 224x224, нормализация ImageNet. Это снимает различия формата файлов.
- Аугментации train (имитация разного качества): повороты до 10 градусов, сдвиг до 5%, масштаб 0.9-1.1, яркость и контраст, размытие, шум. **Флипов нет**: стандартная ориентация среза важна для анатомии, а отражённые копии в исходных данных - артефакт.

## Установка

Нужен Python 3.12 (на 3.9 не проверялось).

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Данные положите в `./data` (или задайте переменную `MRI_DATA_DIR`). Ожидаемая структура: `data/{Train,Test}/{glioma,meningioma,notumor,pituitary}/*.jpg`.
Устройство выбирается автоматически: CUDA, затем Apple MPS, затем CPU.

## Запуск

```bash
python -m src.recon          # разведка: баланс классов, сетка примеров (reports/)
python -m src.data           # чистка, дедупликация, группы, сплит, кэш (reports/splits.csv)
python -m src.train          # обучение (--epochs N, --arch resnet50 --tag resnet50 для бейзлайна)
python -m src.evaluate       # метрики, калибровка, ошибки, Grad-CAM, report.md
python -m src.make_examples  # 4 демо-снимка в examples/
python app.py                # прототип: http://127.0.0.1:7860
```

Чекпоинт `models/best.pt` (16 МБ) в git не входит: обучите модель командой выше или положите файл в `models/` отдельно. Для быстрой проверки конвейера: `python -m src.train --smoke --epochs 2`.

## Прототип

Gradio, интерфейс на русском: загрузка одного или нескольких снимков, предсказанный класс, вероятности по 4 классам, снимок с рамкой и контуром, карта Grad-CAM, текстовое пояснение. При уверенности ниже 70% показывается предупреждение "низкая уверенность, требуется внимание специалиста". Измеренная задержка на CPU (Apple M2, 4 потока): около 0.5 с на снимок вместе с Grad-CAM.

## Ограничения

- **Локализация приблизительная.** В данных нет масок и рамок, поэтому IoU и Dice посчитать нельзя. Вместо этого сделана косвенная проверка: закрытие рамки Grad-CAM снижает уверенность модели в среднем на 0.244, закрытие случайной рамки того же размера - на 0.079 (150 снимков). Это подтверждает важность области для решения модели, но не совпадение с границами опухоли.
- **Нет ID пациентов.** Разбиение по пациентам невозможно, срезы одного пациента могли попасть в разные выборки: метрики могут быть завышены.
- **Один составной источник данных**, внешней валидации на другой клинике и сканере нет. Для реального применения она обязательна.
- **Риск опоры на источник снимка.** Подгруппы тестовой выборки сильно различаются по доле опухолей (все 1-канальные и все 512x512 снимки - опухоли), класс "норма" содержит другие последовательности (T2, FLAIR). Качество в подгруппе "другой размер" ниже: accuracy 96.7%, recall опухолей 92.2%. Модель может частично использовать тип последовательности или формат файла, а не патологию.
- **2D-срезы** вместо 3D-объёмов, без клинических данных.
- **Типичные ошибки:** путаница менингиом с глиомой и опухолью гипофиза (по 4 из 246), глиом с менингиомой (3 из 339), пропуски на T2/FLAIR-срезах (`reports/errors_grid.png`).
- На Apple MPS обучение идёт в fp32 (смешанная точность включается только на CUDA).
- Модель не зарегистрирована как медицинское изделие и не предназначена для клинического применения без регистрации, клинической валидации и подтверждения врачом.

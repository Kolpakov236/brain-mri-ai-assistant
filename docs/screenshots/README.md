# Скриншоты работающего прототипа

Все скриншоты сняты с запущенного приложения (`python app.py`, окно браузера 1500 px по ширине, страница целиком). Чтобы переснять, запустите приложение и откройте http://127.0.0.1:7860.

| Файл | Что показано |
|---|---|
| `01_start.png` | Стартовый экран: шапка, ключевые метрики на test, состав тестовой выборки, загрузка и примеры. |
| `02_glioma.png` | `examples/example_glioma.jpg`: глиома, уверенность 97%, рамка и контур, карта Grad-CAM, вероятности, пояснение. |
| `03_meningioma.png` | `examples/example_meningioma.jpg`: менингиома, уверенность 98%. |
| `04_pituitary.png` | `examples/example_pituitary.jpg`: опухоль гипофиза, уверенность 93%. |
| `05_notumor.png` | `examples/example_notumor.jpg`: опухоль не обнаружена, уверенность 98%, область не выделяется. |
| `06_batch.png` | Пакетная загрузка четырёх примеров: 8 изображений в галерее и 4 карточки результатов. |
| `07_low_confidence.png` | Предупреждение "низкая уверенность, требуется внимание специалиста". **Важно:** это реальная ошибка модели на тестовом снимке (`Tr-me_0359.jpg`, истинный класс менингиома, предсказано "опухоль не обнаружена" с уверенностью 69%). Кадр показывает, что порог 70% помечает такую ошибку для проверки. Не выдавайте его за верное предсказание. |

Не снят (по желанию): загрузка файла, не являющегося изображением. Фильтр `file_types=["image"]` в интерфейсе отсекает такие файлы до анализа.

Графики для презентации лежат в `reports/` (список в `docs/slides_content.md`).
